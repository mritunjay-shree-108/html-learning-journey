    What I Learned Today

    • Heading tags h1 - h6:These are basically heading tags which differ by their level of importance , so as per the level their font size are bigger and smaller.
    • Paragraph tag (p): This is used to define a paragraph of text.
    • Break tag (br): This is used to insert a line break.
    • Unordered list tag (ul): This is used to define an unordered list.
    • Ordered list tag (ol): This is used to define an ordered list.
    • List item tag (li): This is used to define a list item.
    • Anchor tag (a): This is used to create a hyperlink.
    • Image tag (img): This is used to embed an image.
    • Div tag (div): This is used to define a division or a section in the document.
    • Span tag (span): This is used to group inline elements for styling purposes.
    • Bold tag (b): This is used to define bold text.
    • Italic tag (i): This is used to define italic text.
    • Underline tag (u): This is used to define underline text.
    • Horizontal rule tag (hr): This is used to insert a horizontal rule.
    • sup tag (sup): This is used to define superscript text.
    • sub tag (sub): This is used to define subscript text.
    • Semantic tags: These are tags that provide meaning to the content they contain.
    • Header tag (header): This is used to define a header for a section or the entire page.
    • Footer tag (footer): This is used to define a footer for a section or the entire page.
    • Main tag (main): This is used to define the main content of the document.
    • Navigation tag (nav): This is used to define a section of navigation links.
    • Article tag (article): This is used to define an article.
    • Section tag (section): This is used to define a section in the document.
    • Aside tag (aside): This is used to define content that is tangentially related to the content around it.
    • SEO Friendly Tags: These are tags that help search engines understand the structure and content of the page.
    • HTML Entities: These are used to represent special characters in HTML.
    • Comment tag (): This is used to add comments in the HTML code.
    • Emmet: A tool that helps speed up HTML and CSS development.
